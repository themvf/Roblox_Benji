# Ninja soldier character skins

Two selectable R15 match appearances: **Tactical Operator** from the 02:20 GLB and **Sci-Fi Sentry** from the 21:18 GLB. Both source files and matching PNG references are preserved under `source/`. `appraisal.json` documents the tactical source; `review/appraisal-second.json` documents the sentry source. The original textured appraisal sheets are `views.png` and `review/views.png`.

The source models were static, extremely fragmented image-to-3D results. The clean versions are stylized rigid armor rather than direct retopologies. Each piece welds to an R15 body part so normal humanoid animations remain available. The game uses the shared piece specification, not the GLB exports, for match appearance. The GLBs are useful for review, Blender editing, and a future MeshPart replacement. They are armor only, not standalone rigged avatars. No texture image maps are required by these clean builds; colors and materials are specified per part in `source/armor_specs.json`.

Rebuild from the project root with `python tools/build_ninja_skins.py`; use `python tools/build_ninja_skins.py --check-only` to verify without regenerating. Blender 4.3 is the tested renderer; use `--blender "C:\\path\\to\\blender.exe"` for another install. The wrapper backs up generated outputs before replacement. Changes to part placement, color, or number should begin in `tools/build_ninja_skin_specs.py`; the generated Lua definitions and Blender exports then stay in sync.

Local art review files are `review/<Variant>-front.png`, `-side.png`, `-rear.png`, and `-quarter.png`. They show the exported GLB on a neutral R15 stand-in and do not prove actual Studio appearance. `validation.json` records file hashes and mesh counts. Runtime selection is in Customize → Character; selected appearances apply only in a match. The normal avatar returns on a lobby respawn.

Current limits: clean, block-based silhouette is simpler than either high-detail reference; the user requested more detail. Quarter-density source trials retain the standing detail, but posed spatial-segmentation trials fail at the joints. They are saved under `trials/` and are not playable replacements. Detailed production needs clean limb and armor topology plus transferred/recreated texture detail. Visual approval and Studio animation testing remain pending. See `HANDOFF.md` for the stage boundary.

The user also confirmed **full Marketplace character bundles** for both designs. The current game prototypes are not Marketplace assets. See `MARKETPLACE_DELIVERY.md` and the measured `marketplace_readiness.json` for the shared game/catalog target and current gaps. Re-run `python tools/check_ninja_marketplace_readiness.py` after new exports; Roblox Avatar Setup remains the authoritative later validation stage.
