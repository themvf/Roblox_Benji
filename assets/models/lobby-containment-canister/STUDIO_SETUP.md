# Studio setup: lobby containment canister

Import `exports/LobbyContainmentCanister.glb` as a model using Stud units under the intended experience owner. Expect 18 MeshParts, roughly 8 studs high and 4.75 studs across. In the 2026-11-09 ENGAGE import, Studio preserved cap and plume ColorMaps but made every untextured GLB material gray and opaque. The raw import preview is therefore not the delivered appearance. Run the helper below before judging the visual result. Recheck it in the final lobby position and at lower graphics quality.

The helper re-applies the glass tint and transparency, dark interior, cyan light rings, blue wisps and emissive base using the imported mesh names. It leaves the cap and plume image maps in place. The chamber shell uses translucent SmoothPlastic: an initial Glass material test hid the inner energy in Studio's transparency rendering. The decorative canister has no collision.

For the **animated decorative version**, select only the imported model and run `SetupChamberMotion.luau` in the Studio Command Bar. This one helper applies the Studio appearance, anchors all 18 MeshParts, disables collision, reuses the imported blue plume's ColorMap as a particle texture, creates a hidden source near the bottom, emits three slow rising vapor particles per second, and adds a small blue PointLight. The speed and lifetime keep particles in the lower half of an approximately 8-stud chamber in the ENGAGE Play test. If the import did not create a readable plume ColorMap, upload `textures/LobbyContainmentCanister_Energy.png` as an image and set its `rbxassetid://...` value in the model's `EnergyTextureId` attribute before rerunning the helper. The helper is idempotent by name and creates no script inside the editable lobby model. For a static version, use `SetupDecoration.luau` and set material colors manually if needed.

For lobby placement, follow `docs/design/lobby-experience/EDITING.md`: place the approved model under editable `Lobby.Geometry`, save `assets/environment/source/Lobby.rbxm`, run `tools/save_lobby.cmd`, restart Play, and verify the saved lobby. Record owner, IDs, appearance, physics, placement, and restart evidence in `HANDOFF.md`.
