# Studio import check

Import the approved `OfficeChair_Clean.glb` or `OfficeChair_YellowStained.glb` with Scale Unit **Stud**. If an identical export hash has already been uploaded under the intended owner, reuse that upload for additional placements.

Check the imported model in Studio before map placement:

1. Confirm three MeshParts and a height of about five studs, with the wheel bottoms at the model pivot.
2. Compare the seat, back, arms, wheels, and upholstery color with `review/` images. Confirm the two embedded textures load on the imported asset.
3. Record the owning account or group, mesh and texture asset IDs, actual scale, and any adjustments in `HANDOFF.md`.
4. Choose the chair's game role. For decoration, anchor all three MeshParts and disable collision, touch, and query on them. For an interactive seat, add and test a separate Roblox Seat and appropriate collision setup. The GLB alone is visual geometry.
5. Place the approved import into the chosen map's saved decor or prop collection and verify it again after a map restart. Record that placement separately in `HANDOFF.md`.
