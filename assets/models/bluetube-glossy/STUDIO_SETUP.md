# Studio verification for glossy containment tube variants

**Gray preview of any tube:** The five original exports have no image textures. For the next import test choose the matching `exports/*_StudioTextured.glb` copy (blue, green, yellow, cracked/oozing, or faint-occupant). Each separate copy embeds its color maps. Compare both the importer preview and the imported Workspace model; the latter is the actual appearance check. Record whether `SurfaceAppearance.ColorMap` or mesh `TextureID` is populated, plus shell transparency and gloss. Do not treat the preview alone as a successful Studio verification.

For the new blue cracked-and-spilled variant, import `exports/BlueTube_BlueCrackedOozing_StudioTextured.glb`. View the front at player height so the blue ooze visibly exits the opening, continues below the crack and ends in the floor pool. Check the side and quarter views, shell alpha, map lighting, ground contact and collision separately. Its blue stream and pool are static geometry.

Choose and import `exports/BlueTube_Glossy.glb` (cyan core), `exports/BlueTube_GreenCore.glb` (green core), `exports/BlueTube_NeonYellowCore.glb` (intact yellow core), `exports/BlueTube_CrackedOozing.glb` (cracked yellow chamber and spill), `exports/BlueTube_FaintOccupant.glb` (intact blue chamber with a faint figure), or `exports/BlueTube_BlueCrackedOozing_StudioTextured.glb` (cracked cyan chamber with a blue spill) with Scale Unit **Stud** under the intended experience owner. The matching `*_StudioTextured.glb` copies are recommended for the gray-preview problem. They are separate files and should remain distinct from the earlier `BlueTube.glb`. The first three variants contain ten meshes, each cracked variant fourteen, and the shadow variant eleven. Every mesh is under 10,000 triangles.
2. Confirm approximately 12.1 studs of height and a ground pivot (local minimum Y is 0). Confirm the named PBR materials, blue glossy shell, chosen chamber color and glass alpha appear as intended. This rebuild uses material factors rather than image textures. View the shell under the actual map lighting from the front, side, rear and above; compare with the local review images and the user's screenshot.
   For the yellow version, confirm the core, alpha-blended glass and inner rings read fluorescent yellow under both bright and dim map lighting. The GLB's emissive factor may not become Roblox's Neon material automatically. If a true Neon core is desired, select the imported model and run `SetupNeonYellowCore.luau` in Studio's Command Bar, then inspect the result and record it in `HANDOFF.md`.
   For the cracked version, check that the opening is actually visible at the intended viewing angle, that the fracture lines and retained shards read clearly, and that the yellow-green flow joins the floor pool. Check the translucent shell and emissive color under the map's real lighting. Its leak is fixed geometry; no animated flow is included. The neon helper has not been tested on this variant.
   For the faint-occupant version, view the chamber from the front and a front-quarter angle at realistic player distances. Verify that the silhouette reads as a possible person without becoming a bold graphic, and that its low alpha survives import and map lighting. It is a static shadow mesh rather than a rigged character.
3. Choose whether this is non-colliding decoration or layout cover. For decoration, anchor it and turn collision/touch/query off as appropriate for the scene, including the cracked variant's shards and floor pool. If used as cover, collision and fairness require separate map review.
4. Record the chosen variant, owner, mesh/material IDs, observed scale, materials and physics in `HANDOFF.md`. Obtain visual approval for that variant's exact export hash before calling it accepted.
5. Place it in the target map only after Studio verification. Save the decor source and restart the play session to check persistence. Record that evidence separately.

The cyan inner core is opaque and static behind an alpha-blended glass shell. Add a Roblox light or particle effect separately if an illuminated or moving chamber is desired.
