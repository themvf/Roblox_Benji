# Repository handoff entry point

Project conventions are in [CLAUDE.md](CLAUDE.md).

For external-art and game-asset work:

1. Read [the asset delivery workflow](docs/design/ASSET_DELIVERY_WORKFLOW.md).
2. Read the target asset package's HANDOFF.md before acting. Preserve approved
   decisions, verify current files, and resume at the first unverified stage.
3. Record evidence and the next action in that handoff when work stops. Do not
   infer Studio import, publication, or placement from a passing local export.

The current worked example is
[the server rack handoff](assets/models/server-rack/HANDOFF.md).
